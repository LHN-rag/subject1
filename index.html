01

About

웹 퍼블리싱을 학습하며 쌓아가는 기록과 방향입니다.

자기소개

웹디자인 및 웹퍼블리싱을 학습 중인 퍼블리셔 지망생입니다. HTML로 콘텐츠의 구조를 잡고, CSS로 화면을 표현하는 과정에 관심을 갖고 있습니다.

[내용 입력 필요]

학습을 시작한 계기

웹사이트가 어떻게 만들어지는지 궁금해지면서 HTML과 CSS를 배우기 시작했습니다. 화면에 보이는 결과물 뒤에 구조화된 마크업이 있다는 점이 흥미로웠습니다.

웹 제작에서 중요하게 생각하는 점

제목·문단·목록 등 태그를 목적에 맞게 사용해 정보의 위계를 분명히 하는 것, 그리고 읽기 쉬운 여백과 색상으로 콘텐츠를 전달하는 것을 중요하게 생각합니다.

현재 학습 중인 내용

HTML5 기본 태그, 정의 목록·인용문, 네임 앵커, 텍스트 표현 태그, 그리고 선택자·여백·색상 등 기본 CSS 속성을 실습 과제로 익히고 있습니다.

앞으로의 목표

학습한 마크업과 스타일을 바탕으로 반응형 레이아웃과 접근성을 고려한 웹 페이지를 제작할 수 있는 퍼블리셔로 성장하고 싶습니다.

02

Learning Journey

학원 실습을 단계별로 정리한 학습 과정입니다.

  1. 01

    HTML 기본 문서 구조

    웹 페이지의 뼈대가 되는 문서 구조와 메타 정보를 작성하는 방법을 익혔습니다.

    DOCTYPE · lang · charset · viewport · h1 · p · hr · address

  2. 02

    제목과 문단

    제목 태그의 위계와 문단·줄바꿈을 활용해 글의 구조를 나누는 연습을 했습니다.

    h1 · h2 · h3 · p · br · hr

  3. 03

    목록과 중첩 목록

    순서·비순서 목록으로 정보를 분류하고, 중첩 목록으로 계층 구조를 표현했습니다.

    ol · ul · li · type 속성

  4. 04

    텍스트 표현 태그

    강조, 수정, 첨자, 날짜 등 의미에 맞는 텍스트 태그를 문서에 적용했습니다.

    b · i · strong · del · ins · mark · sub · sup · ruby · meter · time

  5. 05

    정의 목록과 인용

    용어 사전 형태의 정의 목록과 인용문을 작성하며 정보 전달 방식을 익혔습니다.

    dl · dt · dd · blockquote · small

  6. 06

    네임 앵커

    id와 href="#영역"을 연결해 긴 문서 안에서 원하는 위치로 이동하는 구조를 만들었습니다.

    id · a(href="#") · 페이지 내 내비게이션

  7. 07

    기본 CSS 스타일

    외부 CSS 파일을 연결하고 선택자·색상·여백·행간으로 화면을 꾸미는 방법을 배웠습니다.

    요소·id·자손 선택자 · color · background-color · margin · padding · line-height

  8. 08

    포트폴리오 제작

    학습 내용을 정리한 개인 포트폴리오 페이지를 HTML과 CSS만으로 제작했습니다.

    Flexbox · Grid · 미디어쿼리 · CSS 변수 · 반응형 레이아웃
