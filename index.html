HTML

  • HTML5 문서 구조 (DOCTYPE, lang, charset, viewport)
  • 제목 태그 (h1 ~ h3)
  • 문단·구분선 (p, hr, br)
  • 순서·비순서 목록 (ol, ul, li)
  • 중첩 목록
  • 정의 목록 (dl, dt, dd)
  • 텍스트 강조 (b, i, strong, small)
  • 텍스트 수정 표시 (ins, del, mark)
  • 인용문 (blockquote)
  • 첨자 (sub, sup)
  • ruby, meter, time 태그
  • address 태그
  • 네임 앵커 링크 (id, href="#")
  • 시맨틱 태그 개념 학습

CSS

  • 외부 CSS 파일 연결
  • 요소·id·자손 선택자
  • 색상 (color, background-color)
  • 여백 (margin, padding)
  • 줄 간격 (line-height)
  • 글자 크기 (font-size)
  • 테두리 (border)
  • 링크 스타일 (text-decoration)
  • 목록 스타일 제거 (list-style)
  • CSS 그라데이션 배경
  • scroll-behavior
